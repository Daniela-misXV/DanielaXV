## Subir a GitHub

Sube `index.html`, `style.css`, `script.js`, `.nojekyll` y la carpeta `assets` a la raíz del repositorio Daniela-misXV/DanielaXV. No subas el ZIP cerrado: extráelo primero.

Para compartir desde GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save. GitHub mostrará el enlace cuando finalice la publicación.
